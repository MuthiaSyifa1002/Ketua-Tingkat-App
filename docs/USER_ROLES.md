# 👥 User Roles & Permissions - Ketua Tingkat App

## 📋 Role Hierarchy

```
Ketua Tingkat (Admin)
    ↓
Wakil Ketua (Co-Admin)
    ↓
Anggota (Member)
```

---

## 👑 KETUA TINGKAT (Administrator)

### Permissions

#### Dashboard
- ✅ View dashboard analytics
- ✅ View class statistics
- ✅ View real-time activity
- ✅ Export reports

#### Jadwal Matakuliah
- ✅ Create/Edit/Delete matakuliah
- ✅ Manage jadwal kuliah
- ✅ Import/Export jadwal
- ✅ Sync ke Google Calendar

#### Manajemen Anggota
- ✅ View semua anggota per angkatan
- ✅ Add/Edit/Delete anggota
- ✅ Bulk import anggota
- ✅ View statistik

#### Absensi
- ✅ View laporan absensi lengkap
- ✅ Analyze kehadiran patterns
- ✅ Export laporan ke Excel/PDF
- ✅ Manage absensi records

#### Pengumuman & Notifikasi
- ✅ Create/Edit/Delete pengumuman
- ✅ Pin pengumuman
- ✅ Schedule posting otomatis
- ✅ Send notifications
- ✅ Track read status

#### Assignment
- ✅ Create/Edit/Delete assignment
- ✅ Upload attachment
- ✅ Grade submissions
- ✅ Send feedback

#### Forum
- ✅ Create/Edit/Delete channel
- ✅ Manage channel members
- ✅ Pin/unpin posts
- ✅ Delete posts/replies
- ✅ Mute/ban members

#### Mading
- ✅ Add/Edit/Delete post
- ✅ Upload gambar/video
- ✅ Arrange layout (drag & drop)
- ✅ View analytics

#### KRS Selection
- ✅ Create matakuliah untuk KRS
- ✅ View KRS semua anggota
- ✅ Manage KRS settings

#### File Sharing
- ✅ Upload/Edit/Delete file
- ✅ Set permissions
- ✅ Organize folders

---

## 👤 WAKIL KETUA (Co-Administrator)

### Permissions (Limited)

#### Dashboard
- ✅ View analytics
- ✅ View statistics

#### Jadwal Matakuliah
- ✅ View matakuliah
- ✅ Create jadwal kuliah
- ✅ Edit jadwal (terbatas)
- ❌ Delete jadwal

#### Manajemen Anggota
- ✅ View semua anggota
- ✅ Edit profil anggota
- ❌ Add/Delete anggota

#### Pengumuman & Notifikasi
- ✅ Create pengumuman
- ✅ Edit pengumuman (milik sendiri)
- ✅ Send notifications

#### Assignment
- ✅ Create assignment
- ✅ Grade submissions
- ✅ Send feedback

#### Forum
- ✅ Create/Manage channel
- ✅ Moderate posts (limited)
- ❌ Ban members (hanya mute)

---

## 👫 ANGGOTA (Member)

### Permissions

#### Dashboard
- ✅ View personal dashboard
- ✅ See upcoming deadlines

#### Jadwal Matakuliah
- ✅ View jadwal
- ✅ Filter by hari/jam
- ✅ Pin jadwal favorit
- ❌ Kelola jadwal

#### Manajemen Anggota
- ✅ View daftar anggota
- ✅ Edit profil pribadi
- ✅ Search anggota
- ❌ Edit profil orang lain

#### Absensi
- ✅ Submit absensi (input NIM)
- ✅ View riwayat pribadi
- ✅ View statistik pribadi
- ❌ View absensi orang lain

#### Pengumuman & Notifikasi
- ✅ View pengumuman
- ✅ Filter by kategori
- ✅ Comment pengumuman
- ✅ Favorite pengumuman
- ❌ Create/Edit/Delete pengumuman

#### Assignment
- ✅ View assignment
- ✅ Download attachment
- ✅ Submit assignment
- ✅ View feedback
- ❌ Grade/Delete assignment

#### Forum
- ✅ View channel
- ✅ Create posts/replies
- ✅ Edit own posts/replies
- ✅ React dengan emoji
- ❌ Manage channel
- ❌ Ban/mute users

#### Mading
- ✅ View mading
- ✅ Like/react pada post
- ✅ View post details
- ❌ Add/Edit/Delete post

#### KRS Selection
- ✅ Checklist matakuliah pribadi
- ✅ View KRS pribadi
- ✅ Update KRS kapan saja
- ✅ Export sertifikat KRS
- ❌ View KRS orang lain

#### File Sharing
- ✅ Browse file
- ✅ Search file
- ✅ Download file
- ✅ Favorite documents
- ❌ Upload/Edit/Delete file
