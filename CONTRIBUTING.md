# 🤝 Contributing to Ketua Tingkat App

Terima kasih telah tertarik untuk berkontribusi pada Ketua Tingkat App! Panduan ini akan membantu Anda memulai.

## 📋 Code of Conduct

- Berperilaku profesional dan menghormati semua kontributor
- Hindari diskriminasi dan harassment
- Fokus pada peningkatan project

## 🚀 Getting Started

### 1. Fork Repository
```bash
git clone https://github.com/MuthiaSyifa1002/Ketua-Tingkat-App.git
cd Ketua-Tingkat-App
```

### 2. Create Feature Branch
```bash
git checkout -b feature/your-feature-name
```

### 3. Setup Development Environment
```bash
npm install
npm run dev
```

## 📝 Commit Guidelines

Format commit message:
```
[TYPE] Brief description

Detailed explanation if needed
```

Types:
- `feat:` New feature
- `fix:` Bug fix
- `docs:` Documentation
- `style:` Code style (formatting, semicolons, etc)
- `refactor:` Code refactoring
- `test:` Adding tests
- `chore:` Build, dependencies, tools

Examples:
```
feat: Add absensi tracking feature
fix: Fix jadwal display bug
docs: Update README
```

## 🔀 Pull Request Process

1. **Create Pull Request** dengan deskripsi jelas
2. **Link Issue** jika ada (`Closes #123`)
3. **Describe Changes** dengan detail
4. **Add Screenshots** untuk UI changes
5. **Wait for Review**
6. **Make Requested Changes**
7. **Merge** setelah approval

## 📚 Documentation

Untuk fitur baru, update dokumentasi di:
- `docs/FITUR_LENGKAP.md` - Feature details
- `docs/DATABASE_SCHEMA.md` - Database changes
- `README.md` - Quick reference

## 🐛 Reporting Bugs

Gunakan GitHub Issues dengan template yang jelas.

## 📞 Questions?

- Buat GitHub Discussion untuk pertanyaan
- Hubungi maintainer via email
- Cek existing issues terlebih dahulu
